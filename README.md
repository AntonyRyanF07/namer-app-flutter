# Namer App

Aplicativo Flutter desenvolvido com base no codelab oficial "Seu primeiro app do Flutter", do Google.

## Funcionalidades

- Geração de pares de palavras aleatórios
- Botão Next para gerar uma nova sugestão
- Botão Like para favoritar ou desfavoritar
- Tela de favoritos
- Remoção de favoritos
- Interface responsiva

## Como executar

1. Instale o Flutter e o VS Code.
2. Abra esta pasta no VS Code.
3. No terminal, execute:

```bash
flutter pub get
flutter run
```

O projeto usa os pacotes `english_words` e `provider`.
